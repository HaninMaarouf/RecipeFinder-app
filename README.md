# 🍳 Recipe Finder App

A responsive recipe search application built using **HTML, CSS, and JavaScript**.  
The app allows users to search for meals, view recipe details, ingredients, and cooking instructions using data from TheMealDB API.

## 🚀 Features

- 🔍 Search recipes by name
- ⌨️ Search using the Enter key
- 🍽 Display recipe cards dynamically
- 🖼 Show recipe images
- 📋 View full recipe details
- 🥘 Display ingredients and measurements
- 📝 Show cooking instructions
- ⚡ Smooth scrolling and animations
- ❌ Error handling for invalid searches
- 📱 Responsive design for mobile and desktop

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- TheMealDB API
